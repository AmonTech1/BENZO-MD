🔧 INSTALLATION

```bash
# Clone the repo (you know you want to)
git clone https://github.com/AmonTech1/BENZO-MD.git
cd BENZO-MD

# Install dependencies (all 2 of them)
npm install

# Actually wait, there's like 50 dependencies
# Okay fine, install them all
npm install --force
# (You might need --force because some dependencies are toxic)

# Start the bot (fingers crossed)
node index.js

# If it doesn't work, just stare at the screen menacingly
# It'll work out of fear 😂
```
